🔁 Lo único que hace un robot

Todo el programa del seguidor cabe en tres palabras que se repiten para siempre:

En Arduino eso es exactamente el loop(). Y la parte del medio — pensar — es lo que vamos a diseñar ahora.

📐 El primer paso: dónde van los sensores

Los dos sensores no van encima de la línea. Van uno a cada lado, con la línea pasando por el medio. Cuando el auto está bien encaminado, ninguno de los dos la ve.

Suena raro la primera vez. Pensalo así: son como los dos bordes de un carril. Si estás en el medio, no tocás ninguno. Si tocás el de la izquierda, es porque te fuiste para la izquierda.

🤔 Discutan esto antes de seguir (5 minutos, en grupo)

Si el sensor izquierdo es el que está tocando la línea negra… ¿hacia qué lado se corrió el auto? ¿Y para volver al centro, qué rueda conviene frenar? Poné las manos sobre la mesa como si fueran las ruedas y actuenlo. Casi todos se equivocan la primera vez, y está bien: equivocarse acá es mucho más barato que equivocarse en la pista.

✏️ La tabla de verdad

Dos sensores, cada uno con dos estados posibles → 2 × 2 = 4 casos. Nada más. Todo el comportamiento del auto cabe en cuatro renglones.

Convención: 0 = ve blanco (no hay línea) · 1 = ve negro (hay línea).

🔄 La regla de oro (la que cuesta)

Frenás la rueda del lado que ve la línea.
Sensor izquierdo ve negro → freno la rueda izquierda → el auto pivota hacia la izquierda → la línea vuelve al centro. Parece al revés, pero probalo con el simulador de acá abajo y se te va a acomodar la cabeza.

💻 El código completo

Acá está todo junto: los pines del L298N de la parada 2, los sensores de la parada 3, y la tabla de verdad que acabás de completar. Fijate que las cuatro ramas del if son exactamente los cuatro casos de la tabla.

04_seguidor_linea.ino ⬇ .ino 
// ============================================================
//  SEGUIDOR DE LINEA - version basica con 2 sensores
//  Taller de Robotica
// ============================================================

// ---------- Motores (puente H L298N) ----------
const int ENA = 5, IN1 = 6, IN2 = 7;    // motor izquierdo
const int IN3 = 8, IN4 = 9, ENB = 10;   // motor derecho

// ---------- Sensores infrarrojos ----------
const int SENSOR_IZQ = 2;
const int SENSOR_DER = 3;

// Cambia esto a LOW si TU sensor da 0 sobre el negro
// (lo descubriste en el desafio 1 de la parada 3)
const int VE_LINEA = HIGH;

// ---------- Velocidades: aca se ajusta todo ----------
const int VEL_NORMAL = 150;   // cuando va derecho
const int VEL_GIRO   = 170;   // la rueda de afuera al corregir
const int VEL_FRENO  = 0;     // la rueda de adentro al corregir

void setup() {
  pinMode(ENA, OUTPUT); pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); pinMode(ENB, OUTPUT);

  pinMode(SENSOR_IZQ, INPUT);
  pinMode(SENSOR_DER, INPUT);

  Serial.begin(9600);

  // 2 segundos para sacar la mano antes de que arranque
  frenar();
  delay(2000);
}

void loop() {
  // ---------- 1. SENSAR ----------
  bool izq = (digitalRead(SENSOR_IZQ) == VE_LINEA);
  bool der = (digitalRead(SENSOR_DER) == VE_LINEA);

  // ---------- 2. PENSAR y 3. ACTUAR ----------
  if (!izq && !der) {
    // Caso A: la linea esta en el medio
    adelante();

  } else if (izq && !der) {
    // Caso B: me fui a la derecha -> vuelvo a la izquierda
    corregirIzquierda();

  } else if (!izq && der) {
    // Caso C: me fui a la izquierda -> vuelvo a la derecha
    corregirDerecha();

  } else {
    // Caso D: los dos ven negro -> cruce o llegada
    frenar();
  }
}

// ============================================================
//  Los movimientos
// ============================================================

void adelante() {
  motorIzquierdo(VEL_NORMAL);
  motorDerecho(VEL_NORMAL);
}

void corregirIzquierda() {
  motorIzquierdo(VEL_FRENO);   // freno la de adentro
  motorDerecho(VEL_GIRO);      // acelero la de afuera
}

void corregirDerecha() {
  motorIzquierdo(VEL_GIRO);
  motorDerecho(VEL_FRENO);
}

void frenar() {
  motorIzquierdo(0);
  motorDerecho(0);
}

// ============================================================
//  Control de cada motor por separado.
//  Velocidad positiva = adelante. Negativa = atras.
// ============================================================

void motorIzquierdo(int velocidad) {
  if (velocidad >= 0) {
    digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  } else {
    digitalWrite(IN1, LOW);  digitalWrite(IN2, HIGH);
    velocidad = -velocidad;
  }
  analogWrite(ENA, constrain(velocidad, 0, 255));
}

void motorDerecho(int velocidad) {
  if (velocidad >= 0) {
    digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
  } else {
    digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH);
    velocidad = -velocidad;
  }
  analogWrite(ENB, constrain(velocidad, 0, 255));
}
🧩 Dos cosas del código que vale la pena mirar
  • motorIzquierdo(-120) hace que esa rueda vaya para atrás. Todavía no lo usamos, pero está listo para el desafío 3 y para la parada 7.
  • Toda la personalidad del auto está en tres números: VEL_NORMAL, VEL_GIRO y VEL_FRENO. No vas a tocar la lógica nunca más: de acá en adelante, ajustar el auto es ajustar esos tres números.

Medio

Antes de soltarlo en la pista: levantá el auto, agarrá una hoja con una tira de cinta negra y movela debajo de los sensores. Las ruedas tienen que reaccionar de la forma correcta a cada movimiento.

Esta prueba te ahorra media hora de perseguir el auto por el aula. Si acá las ruedas hacen lo contrario de lo que esperás, tenés uno de estos tres problemas — y ahora podés distinguirlos:

  1. Los cables de un motor están al revés (una rueda gira al revés).
  2. Los sensores están cruzados (el del pin 2 es en realidad el derecho).
  3. Tu VE_LINEA está al revés (probá cambiar HIGH por LOW).
Difícil

Frenar cuando los dos sensores ven negro es una decisión, no una verdad. Probá estas tres alternativas en la pista real y decidí cuál te conviene:

  1. Frenar (lo que está ahora). Bueno si querés detectar la línea de llegada.
  2. Seguir derecho. Bueno si tu pista tiene cruces: el auto los atraviesa sin pensar.
  3. Seguir haciendo lo último que hacía. El más astuto de los tres. Necesitás guardar la última acción en una variable que sobreviva entre vueltas del loop().
Cómo se recuerda algo entre vueltas del loop

Una variable declarada afuera de loop() conserva su valor de una vuelta a la otra. Es la memoria del robot.

idea
// afuera del loop, arriba de todo:
int ultimaAccion = 0;   // 0 = derecho, 1 = izquierda, 2 = derecha

// dentro del loop, en cada caso, antes de actuar:
ultimaAccion = 1;

// y en el caso D:
if (ultimaAccion == 1)      corregirIzquierda();
else if (ultimaAccion == 2) corregirDerecha();
else                        adelante();

Esta misma idea, aplicada a "me quedé sin línea", es lo que hace que un auto de competencia recupere la pista después de salirse. Lo vemos en la parada 7.
