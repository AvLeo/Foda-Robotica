👁️ Parada 3 · Los ojos

Los sensores infrarrojos

Ya sabemos mover el auto. Ahora hay que enseñarle a mirar.

⏱️ 1h – 1h 30 🎯 4 desafíos 💻 Monitor Serie
🎯 Al terminar esta parada vas a poder…
  • Explicar cómo un sensor "ve" sin tener ojos.
  • Leer los dos sensores desde el Monitor Serie y saber qué está viendo cada uno.
  • Calibrar el potenciómetro hasta que la lectura sea confiable.
  • Encontrar la altura correcta de montaje… midiendo, no adivinando.

🧠 ¿Cómo hace para ver?

El módulo tiene dos "ojos" chiquitos, uno al lado del otro. Uno es un LED infrarrojo que emite luz que nosotros no vemos, y el otro es un fototransistor que mide cuánta de esa luz vuelve rebotada.

Y acá está todo el truco, que es de física de primaria:

El blanco refleja casi toda la luz; el negro la absorbe y la convierte en calor. Es lo mismo que sentís cuando te ponés una remera negra al sol.

💡 ¿Por qué luz infrarroja y no común?

Porque la luz del aula cambia todo el tiempo (alguien prende una lámpara, entra sol por la ventana, pasa una sombra). El infrarrojo no está tan presente en la luz artificial, así que el sensor mide sobre todo su propia luz rebotada. Igual, la luz del sol tiene un montón de infrarrojo: por eso estos autos se vuelven locos al lado de una ventana.

🔍 El módulo por dentro

Tu módulo (TCRT5000 o FC-51) tiene tres partes que te importan:

ParteQué hace
El par de ojosEmiten y reciben infrarrojo. Van mirando al piso.
El potenciómetro azulAjusta a partir de cuánta luz reflejada considera "hay línea". Es la calibración.
Los LED indicadoresUno se prende cuando hay alimentación; el otro, cuando el sensor detecta. Sirven para calibrar sin computadora.
Pin OUTDa HIGH o LOW según lo que ve. Ya es una decisión tomada: sí o no.
❓ ¿El negro es 1 o es 0?

Depende de tu módulo. Hay dos variantes dando vueltas y las dos son comunes. Por eso no vamos a asumir nada: el desafío 1 es justamente descubrirlo.

En todo el material vamos a usar la convención negro = 1, blanco = 0. Si tu sensor es al revés, el código trae una línea para darlo vuelta sin tocar nada más.

🔋 ¿Y si no me alcanzan los pines de 5V?

El Arduino Uno tiene un solo pin de 5V y tres de GND. Con dos sensores ya te quedaste corto. Solución: una protoboard chica. Llevás un cable de 5V y uno de GND del Arduino a dos filas de la protoboard, y de ahí alimentás los dos sensores. Cuando pasemos a 4 sensores en la parada 7 esto deja de ser opcional.

💻 Leer lo que ve el sensor

El Monitor Serie es tu ventana al cerebro del robot. Este programa no mueve nada: solo te muestra, diez veces por segundo, qué está viendo cada ojo.

03a_leer_sensores.ino ⬇ .ino 
// ============================================
//  Parada 3 - Leer los sensores
//  No mueve nada. Solo mira y cuenta lo que ve.
// ============================================

const int SENSOR_IZQ = 2;
const int SENSOR_DER = 3;

void setup() {
  pinMode(SENSOR_IZQ, INPUT);
  pinMode(SENSOR_DER, INPUT);

  Serial.begin(9600);          // abrir la conversacion con la compu
  Serial.println("Sensores listos. Pasa la mano por abajo.");
}

void loop() {
  int izq = digitalRead(SENSOR_IZQ);
  int der = digitalRead(SENSOR_DER);

  Serial.print("IZQ: ");
  Serial.print(izq);
  Serial.print("   DER: ");
  Serial.print(der);

  // Un dibujito para leerlo de un vistazo
  Serial.print("   [");
  Serial.print(izq == 1 ? "#" : ".");
  Serial.print(der == 1 ? "#" : ".");
  Serial.println("]");

  delay(100);   // 10 lecturas por segundo, para poder leerlo
}
🖥️ Para abrir el Monitor Serie

En el IDE de Arduino: Herramientas → Monitor Serie, o el ícono de la lupa arriba a la derecha, o Ctrl+Shift+M. Importante: abajo a la derecha del monitor tiene que decir 9600 baudios, el mismo número que pusiste en Serial.begin(9600). Si no coinciden, ves jeroglíficos.

🚀 Desafíos

Fácil

Cargá 03a_leer_sensores.ino, abrí el Monitor Serie y completá esta tabla en tu carpeta:

Qué le pongo abajoSensor izquierdoSensor derecho
Papel blanco a 1 cm________
Cinta negra a 1 cm________
Nada (apuntando al aire)________
La palma de tu mano________

Con eso ya sabés si tu sensor da 1 o 0 sobre el negro. Anotalo en grande, lo vas a necesitar en la parada 4. Y fijate qué pasa apuntando al aire: ¿se parece más al blanco o al negro? ¿Por qué?

Medio

Con el destornillador chico, girá el potenciómetro azul mientras mirás el LED indicador del módulo. Buscá el punto en el que:

  • Sobre el blanco el LED está de un modo…
  • …y al pasar a la cinta negra cambia, de forma clara y repetible.

El punto justo está más o menos en el medio entre los dos extremos donde deja de cambiar. Si lo dejás demasiado cerca de un borde, cualquier sombra lo hace fallar.

Los dos sensores hay que calibrarlos por separado, uno nunca queda igual que el otro. Movelos sobre la pista de verdad, no sobre una hoja suelta.

El truco del barrido

Girá el pot despacio hasta que el LED justo cambia: ese es el borde A. Seguí girando para el otro lado hasta que vuelve a cambiar: borde B. Ahora poné el pot en el punto medio entre A y B. Ese es el lugar más robusto, el que más aguanta cambios de luz.

Medio

Programá el LED que ya viene en la placa (pin 13, LED_BUILTIN) para que se prenda cuando cualquiera de los dos sensores vea negro. Así podés probar el auto sin tener la compu al lado.

03b_led_testigo.ino ⬇ .ino 
// ============================================
//  Parada 3 - LED testigo
//  Se prende cuando algun sensor ve la linea.
// ============================================

const int SENSOR_IZQ = 2;
const int SENSOR_DER = 3;

// Cambia esto si TU sensor da 0 sobre el negro:
const int VE_LINEA = HIGH;

void setup() {
  pinMode(SENSOR_IZQ, INPUT);
  pinMode(SENSOR_DER, INPUT);
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  bool izq = (digitalRead(SENSOR_IZQ) == VE_LINEA);
  bool der = (digitalRead(SENSOR_DER) == VE_LINEA);

  if (izq || der) {
    digitalWrite(LED_BUILTIN, HIGH);
  } else {
    digitalWrite(LED_BUILTIN, LOW);
  }
}

Extra: modificá el programa para que el LED parpadee rápido si ven negro los dos, y quede fijo si lo ve uno solo. Vas a necesitar millis() o un delay() corto.

Lo que vas a encontrar (no lo abras antes de medir)

Muy pegado al piso, el cono de luz es tan chiquito que cualquier irregularidad lo confunde, y además raspa. Muy alto, vuelve poca luz y el contraste entre blanco y negro se hace demasiado chico. La zona buena para el TCRT5000 suele estar entre 5 y 15 mm. Y sí: el sol arruina todo, porque tiene muchísimo infrarrojo.
